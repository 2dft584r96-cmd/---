# Оформление и продуктовые решения

## Источник бренда

Предоставленный пользователем файл `АПЕКС-РАДИО_медиа-кит.pptx`, 8 слайдов. Медиа-кит использован как визуальный источник; полного нормативного брендбука в задаче не было.

- `public/logo.png` — оригинальное изображение `ppt/media/image-1-1.png`, извлечённое без перерисовки и изменения пропорций.
- Основные цвета из XML слайдов: жёлтый `#F3C217`, тёмно-синий `#0F172A`, синий `#1565D8`, белый `#FFFFFF`, светлый `#F7F7F4`, разделители `#E8ECF3`.
- Шрифт в медиа-ките — Arial; в интерфейсе используется Arial с системными резервными вариантами.
- Слоган «В ритме любимого города» взят из медиа-кита.
- Название, логотип и материалы АПЕКС-РАДИО используются для запрошенного внутреннего приложения. Это не лицензия на распространение бренда третьими лицами.

Цифры об аудитории и рекламные заявления из презентации не переносились в рабочий интерфейс: они не нужны для общения сотрудников.

## Сценарии Slack

Основная структура: рабочее пространство → тематические каналы / личные разговоры → сообщения / ветки ответов. Дополнительные действия: реакции, поиск и сохранение важного. Навигация постоянна, поле ввода закреплено внизу, обсуждение открывается рядом с исходной перепиской.

Официальные страницы, к которым предпринималось обращение:

- https://slack.com/features
- https://slack.com/help/articles/360059928654-How-to-use-Slack--your-quick-start-guide

Обе страницы вернули HTTP 403 из данной среды. Текущий текст этих страниц не удалось изучить; реализация основана на известных сценариях Slack и потребностях радиокоманды. Интерфейс, код и визуальный стиль созданы самостоятельно. Совместимость с API Slack и миграция истории не заявляются.

## Адаптация к радиостанции

Каналы для эфира, редакции и музыки, русские подписи и сообщения об ошибках, оригинальный логотип и сочетание жёлтого с тёмно-синим. Экран демонстрации содержит вымышленные имена и примеры редакционной переписки; рабочая база создаётся пустой, без этих сообщений.

Основной интерфейс поддерживает клавиатуру, видимый фокус, Escape для диалогов, Ctrl/Cmd+K для поиска и Shift+Enter для новой строки. В узком окне список каналов открывается отдельной панелью. Системное предпочтение уменьшения анимации учитывается.
